Directories: Overview¶

As with files, directories are also represented by inodes in the file system.

  • Each directory contains:

    • References to itself (.) and its parent (..)

    • References to other inodes (ie. entries)

  • Each process tracks its current working directory:

    # Get current working directory of process
>>> os.getcwd()

Many of the file system operations we might use unix commands for can be accomplished with Python functions:

Directories: Listing / Walking¶

os.listdir¶

# List all entries under root directory along with size
for name in os.listdir(root):       # Strings
    path = os.path.join(root, name)
    print(f'{path} {os.path.getsize(path)}')

os.scandir¶

# List all entries under root directory along with size
with os.scandir(root) as entries:   # DirEntry objects
    for entry in entries:
        print(f'{entry.path} {entry.stat().st_size}')

Using os.scandir instead of os.listdir can significantly increase the performance of code that also needs file type or file attribute information.

os.walk¶

# Walk the /etc directory and print out files and their sizes
for root, dirs, files in os.walk('/etc/'):
    for name in files:
        path = os.path.join(root, name)
        print(f'{path} {os.path.getsize(path)}')

Directories: list_rec.py (Recursive)¶

Write a simplified version of [ls] that lists the files in directory (possibly recursively) along with the corresponding file sizes.

$ ./list_rec.py  -h
Usage: list [directory]
    -R      List the contents of all directories recursively

#!/usr/bin/env python3

import os
import stat
import sys

# Functions

def usage(status: int=0):
    print('''Usage: list [directory]
    -R      List the contents of all directories recursively
''', file=sys.stderr)
    sys.exit(status)

def walk_directory(path: str, recursive: bool=False):
    ''' Traditional recursive approach '''
    if not os.path.isdir(path) or not os.access(path, os.R_OK):
        return

    with os.scandir(path) as entries:
        for entry in entries:
            if entry.is_dir() and recursive:
                walk_directory(entry.path, recursive)
            elif entry.is_file():
                print(f'{entry.path} {entry.stat().st_size}')

# Main Execution

def main(arguments: list[str]=sys.argv[1:]):
    recursive = False

    while arguments and arguments[0].startswith('-'):
        match argument := arguments.pop(0):
            case '-R': recursive = True
            case '-h': usage(0)
            case _   : usage(1)

    root = arguments[0] if arguments else os.curdir
    walk_directory(root, recursive)

if __name__ == '__main__':
    main()

OOP: Inheritance¶

Inheritance is a core OOP principle that enables the creation of hierarchical relationships between units to allow for code reuse.

class PathEntry(Path):
  @property
  def path(self):
      return self.parent / self

@dataclass
class BaseWalker(ABC):
    entry:  os.DirEntry | PathEntry

    @abstractmethod
    def walk(self, recursive: bool=False):
        pass

class NoopWalker(BaseWalker):
    def walk(self, recursive: bool=False):
        pass

To define an interface, we can create an abstract base class and mark abstract methods which need to be defined by concrete classes that inherit from this ABC.

OOP: Factory Method Pattern¶

The factory design pattern uses a specialized factory method that produces instantiated objects. This is done to abstract away complex object instantiation logic.

  • Product: An interface or abstract class shared by all objects the factory produces.

  • Concrete Products: Specific classes that implement product interface.

  • Concrete Creator: Specific factory method that returns concrete products.

class FileWalker(BaseWalker):
    def walk(self, recursive: bool=False):
        print(f'{self.entry.path} {self.entry.stat().st_size}')

class DirectoryWalker(BaseWalker):
    def walk(self, recursive: bool=False):
        try:
            with os.scandir(self.entry.path) as entries:
                for entry in map(WalkerFactory.get_walker, entries, cycle([recursive])):
                    entry.walk(recursive)
        except PermissionError:
            pass

class WalkerFactory:
    @classmethod
    def get_walker(cls, entry: os.DirEntry | PathEntry, recursive: bool=False) -> BaseWalker:
        match stat.S_IFMT(entry.stat().st_mode):
            case stat.S_IFREG: return FileWalker(entry)
            case stat.S_IFDIR: return DirectoryWalker(entry) if recursive else NoopWalker(entry)
            case _:            return NoopWalker(entry)
