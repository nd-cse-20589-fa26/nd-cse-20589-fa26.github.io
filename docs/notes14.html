Review: Sorting, Lambda¶

To quickly define short functions, we can use the lambda expression which allows us to create one-line functions that consist of a single expression.

def last_name(p):
    return p.last

print(last_name(People[-1]))

# Sort by last name

for p in sorted(People, key=last_name):
    print(p.first, p.last)

# Sort by last name using lambda

for p in sorted(People, key=lambda p: p.last):
    print(p.first, p.last)

# Sort by last name then first name using lambda

for p in sorted(People, key=lambda p: (p.last, p.first):
    print(p.first, p.last)

Functional Programming: Map¶

To transform a sequence into another sequence, we can use the map higher order function:

map(func, seq)

map takes a function func applies it to each of the elements in the sequence seq.

# Compute Individual Scores - Functional v1
# Discuss: map, generator

scores = []
for student in csv.reader(data):
    points = sum(map(float, student))
    scores.append(points)

print(sum(scores))

# Compute Individual Scores - Functional v2

scores = map(
    lambda student: sum(map(float, student)),
    csv.reader(data)
)

print(sum(scores))

Functional Programming: List Comprehensions¶

Because map and filter is so common and lambdas can be a bit tricky to use, Python provides some syntactic sugar called list comprehensions which allow us to concisely construct new lists.

# List Comprehension Structure

list_comprehension = [
    element
    for element in seq
    if condition
]

# Compute Individual Scores - List Comprehension v1
# Discuss: list comprehension

scores = [
    sum(map(float, student))
    for student in csv.reader(data)
]

print(sum(scores))

# Compute Individual Scores - List Comprehension v2

scores = [
    sum([float(point) for point in student])
    for student in csv.reader(data)
]

print(sum(scores))

Functional Programming: Filter¶

To traverse a sequence of values and extract a few particular values, Python provides the filter function:

filter(func, seq)

filter takes a function func applies it to each of the elements in the sequence seq. If the result is True, then the element is included in the resulting sequence.

# Filter scores - Imperative

Bs = []
for score in scores:
    if .8*MAX <= score < .9*MAX:
        Bs.append(score)

print(len(Bs))

# Filter scores - Functional

Bs = filter(lambda score: .8*MAX <= score < .9*MAX, scores)
print(len(list(Bs)))

# Filter scores - List Comprehension

Bs = [score for score in scores if .8*MAX <= score < .9*MAX]
print(len(Bs))

Functional Programming: Data Parallelism¶

Functional programming maps well to problems that exhibit data parallelism:

Concurrent execution of the same task across the elements of a dataset.

In such situations, the dataset normally exhibits data independence, meaning each element can be processed independently of the other.

Functional Programming: Concurrent Futures¶

Once our program is structured to use map, we can use the concurrent.futures module to perform parallel execution:

import hashlib
import os
import concurrent.futures
import sys

# Hash Function

def sha1sum(p):
    with open(p) as stream:
        return hashlib.sha1(stream.read().encode()).hexdigest()

# Create a pool of processes and compute hash in parallel

arguments = sys.argv[1:]

with concurrent.futures.ProcessPoolExecutor(4) as executor:
    hashes = executor.map(sha1sum, arguments)

for p, h in zip(arguments, hashes):
    print(f'{h}  {p}')
