Review: Functional Programming¶

    A way of problem solving based on certain principles.

  • What is functional programming?

    Construct programs as a composition of functions that transform streams.

Functional Programming: Data Parallelism¶

Functional programming maps well to problems that exhibit data parallelism:

Concurrent execution of the same task across the elements of a dataset.

In such situations, the dataset normally exhibits data independence, meaning each element can be processed independently of the other.

#!/usr/bin/env python3

import hashlib
import os
import sys

# Hash Function

def sha1sum(path: str):
    ''' Compute sha1sum digest of the contents of path. '''
    try:    # Discuss: rb, hashlib
      with open(path, 'rb') as stream:
            return hashlib.sha1(stream.read()).hexdigest()
    except OSError:
        pass

# Compute sha1sum of all arguments
# Review: arguments, imperative
arguments = sys.argv[1:]

# Version 0: Imperative
digests = []
for argument in arguments:
    digests.append(sha1sum(argument))

# Version 1: List comprehension
digests = [sha1sum(argument) for argument in arguments]

# Version 2: Functional Programming
digests = map(sha1sum, arguments)

# Version 3: Functional Programming (with Parallelism)
with concurrent.futures.ProcessPoolExecutor() as executor:
    digests = executor.map(sha1sum, arguments)

# Display sha1sum of all arguments
# Discuss: zip -> iterator
for argument, digest in zip(arguments, digests):
    print(f'{digest}  {argument}')

Iterators: Not a List¶

>>> r = reversed(range(5))  # Reverse iterator Range object
>>> r
<range_iterator object at 0x7efc439a0bd0>

>>> for i in r: print(i)
...
>>> for i in r: print(i)    # Already consumed!

>>> r = reversed(range(5))
>>> r[0]                    # IndexError

>>> r = list(reversed(range(5)))
>>> r[0]                    # IndexError

Iterators: Protocol (OOP)¶

#!/usr/bin/env python3

class Countdown:

    # Review: Constructor
    def __init__(self, n: int=10):
        self.n = n

    # Discuss: iter()
    def __iter__(self):
        return self

    # Discuss: next()
    def __next__(self):
        if self.n == 0:
            raise StopIteration
        self.n -= 1
        return self.n

countdown = Countdown()
print(next(countdown))
print(next(countdown))
print()

for c in countdown:
    print(c)

Generators: Lazy Evaluation (Skit)¶

List¶

  • TA grades exams one at a time
  • TA puts graded exams into buffer (box)
  • TA then passes whole box to next grader

Generator¶

  • TA grades exams one at a time
  • TA passes exams to next grader

  • Concurrency / Pipelining!

  • Less memory usage (no DS)

With a generator, we perform lazy evaluation:

  1. Start evaluation of function until we reach yield statement.

  2. When we reach the yield statement, suspend or pause the function and return the expression to the caller.

  3. When the function is called again, resume or continue where we left off.

# Discuss:
#   - return finishes a function
#   - yield suspends function, gives back result, and we resume when called
#     again
def triples(sequence: Iterable[Any]) -> Iterator[Any]:
    for i in sequence:
      yield i * 3   # Discuss: Suspend, Give, later Resume

    # Generator expression
    return (i*3 for i in sequence)

Generators: Task Parallelism¶

Generators support problems that exhibit task parallelism:

Concurrent execution of the different tasks on same or different datasets.

In such situations, the different tasks usually must communicate and coordinate with each other.
The concurrent execution of such tasks are interleaved throughout the execution of the application.

Generators: Reading 05¶

def odds_fp(stream=sys.stdin) -> Iterator[int]:
    return filter(lambda n: n % 2, map(int, stream))

def odds_lc(stream=sys.stdin) -> list[int]:
    return [int(n) for n in stream if int(n) % 2]

def odds_gr(stream=sys.stdin) -> Iterator[int]:
    for line in stream:
        number = int(line)
        if number % 2:
            yield number

def odds_ge(stream=sys.stdin) -> Iterator[int]:
    return (n for n in map(int, stream) if n % 2)
