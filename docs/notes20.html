Environments: Overview¶

A Python virtual environment (ie. venv) is a way to create an isolated workspace for your project and its dependencies.

  • Does not require root permisions.

  • Allows you to change interpreters.

  • Allows you to install different libraries.

Environments: Creation¶

To create a virtual environment, go to your project directory and run:

# Create virtual environment in .venv directory
$ python3 -m venv .venv

# List contents of virtual environment
$ ls .venv
bin/  include/  lib/  lib64@  pyvenv.cfg

This will download and install a Python run-time into the .venv directory (same version).

# Review tree
$ tree .venv

# Review find
$ find .venv

Environments: Activation¶

To activate the virtual environment, source the provided .venv/bin/activate script:

# Activate virtual environment
$ source .venv/bin/activate

This will modify your shell prompt by adding a (.venv) to the end of PS1.

# Deactivate virtual environment
$ deactivate

# Explore activate script
$ vim .venv/bin/activate  # Review: PATH

Environments: Installation¶

To install packages in the virtual environment, use the pip command:

# Attempt to load requests
$ python3
>>> import requests
...

# Install requests library
$ pip install requests

# Upgrade pip library
$ pip install --upgrade pip

The pip command will download and install the libraries to the .venv/lib/pythonX.YZ/site-packages/ folder (where X.YZ is the version number).

import requests

    filename = os.path.basename(url)

    with open(filename, 'wb') as stream:
        stream.write(response.content)
