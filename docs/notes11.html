Pipelines: subprocess¶

In Python, we can create a pipeline by using functions from the subprocess module to chain proceses:

# Pipeline in Shell
ps aux | grep pbui | wc -l

# Pipeline in Python
from subprocess import Popen, PIPE, DEVNULL, run

ps   = Popen(['ps', 'aux'], stdout=PIPE, stderr=DEVNULL)
grep = Popen(['grep', 'pbui'], stdin=ps.stdout, stdout=PIPE)
wc   = run(['wc', '-l'], stdin=grep.stdout, stdout=PIPE)

print(wc.stdout.decode(), end='')

How many bash processes are on there on student10.cse.nd.edu?

# Python Solution

count = 0
for line in os.popen('ps aux'):
    if 'bash' in line:
        count += 1
print(count)

# Pipeline Solution

ps aux | grep -v grep | grep bash \
       | wc -l

Pipelines: Demonstration (2)¶

How many different users processes are on there on student10.cse.nd.edu?

# Python Solution

users = set()
for line in os.popen('ps aux'):
    user = line.split()[0]
    users.add(user)

print(len(users))

# Pipeline Solution

ps aux | awk '{print $1}' \
       | sort | uniq \
       | wc -l

Pipelines: Demonstration (3)¶

Who has the most processes on student10.cse.nd.edu?

# Python Solution

counts = {}
for line in os.popen('ps aux'):
    user = line.split()[0]
    counts[user] = counts.get(user, 0) + 1

max_user = None
for user, count in counts.items():
    if count > counts.get(max_user, 0):
        max_user = user

print(max_user)

# Pipeline Solution

ps aux | awk '{print $1}' \
       | sort | uniq -c \
       | sort -rn | head -n 1 \
       | awk '{print $2}'
