Homework 10: Web Application

  • Home

For this assignment, you are to build a full-stack web application consisting of the following components:

  1. Back-end: This is a Python application that uses the vial.py framework discussed in class.

  2. Database: This is a SQLite database that is used by the web application.

  3. Front-End: This is HTML and CSS that formats the information from the web application.

  4. Unit Test: This uses unittest to verify the correctness of the Python back-end.

The exact requirements for each of these components are specified below.

Activity 0: Preparation¶

Before starting this homework assignment, you should first perform a git pull to retrieve any changes in your remote GitHub repository:

$ cd path/to/repository                   # Go to assignments repository

$ git switch master                       # Make sure we are in master branch

$ git pull --rebase                       # Get any remote changes not present locally

Next, create a new branch for this assignment:

$ git switch -c homework10                # Create homework10 branch and check it out

Task 1: Vial¶

To help you get started, the instructor has provided you with vial.py:

# Create homework10 folder
$ mkdir homework10

# Go to homework10 folder
$ cd homework10

# Download Vial from Slides 31
$ curl -LO https://raw.githubusercontent.com/nd-cse-20589-fa26/examples/refs/heads/master/slides31/vial.py

Task 2: Initial Import¶

Now that the files are downloaded into the homework10 folder, you can commit them to your git repository:

$ git add Makefile                            # Mark changes for commit
$ git add *.py
$ git commit -m "Homework 10: Initial Import" # Record changes

Requirements¶

For this assignment, you are free to implement any web application that you wish as long as you meet the following requirements.

Back-end
  • Must implement a REST API that uses JSON as the data format.
  • Must have at least one GET endpoint.
  • Must have at least one POST or PUT endpoint.
  • Must have at least one DELETE endpoint.
Database
  • Must have at least one table with at least 3 columns.
  • Must use at least one SELECT SQL statement.
  • Must use at least one INSERT or UPDATE SQL statement.
  • Must use at least one DELETE SQL statement.
Front-end
  • MUST have endpoints that use the following HTML tags: a, p, div, li, table, img.
  • MUST use CSS to format the following attributes: background, font-family, font-size, color, margin, padding.
  • MUST implement a HTML form that interacts with the back-end.
Testing
  • Must use automatically start web application.
  • Must use unittest to test every REST API endpoint.
  • Must use check for both successful requests and failed requests.

Once again, the exact web application is up to you. That said, here are some possible ideas:

  1. Todo List
  2. Dashboard / Scoreboard
  3. Bookmark manager
  4. Audio/Video manager
  5. Budget
