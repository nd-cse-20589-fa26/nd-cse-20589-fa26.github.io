Everyone:

Next week, we will explore another programming paradigm called object-oriented programming, which we have been using implicitly anytime we accessed methods or attributes of objects in Python:

Object-oriented programming (OOP) is a programming paradigm based on objects – software entities that encapsulate data and function(s).

Additionally, we dive deeper into the computing stack to understand how something like concurrent.futures works by examining system calls that create and manage processes.

TL;DR¶

The focus of this reading is to allow you to explore object-oriented programming and using processes with low-level system calls in Python.
