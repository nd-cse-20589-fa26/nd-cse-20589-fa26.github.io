Activity 1: playlist_server (0.8 Points)¶

For this activity, you are to write playlist_server.py, which is a web application that uses the vial.py micro-framework to implement the following REST API:

Method Endpoint Description
POST /playlist

Create a playlist with the given name.

Request Payload (JSON)

{"name": str}

Response Codes

  1. 200: Operating successful.
  2. 400: name missing from form data.

Response Body (JSON)

{"id": int}
DELETE /playlist/{playlist_id}

Remove specified playlist.

Response Codes

  1. 200: Operating successful.
  2. 404: Invalid playlist_id.
GET /playlist/{playlist_id}

Get specified playlist.

Response Codes

  1. 200: Operating successful.
  2. 404: Invalid playlist_id.

Response Body (JSON)

{
 "id": int,
 "name": str,
 "items": {
   "total": int,
   "items": [{"title": str, "url": str}, ...]
  }
}

The first three operations allow you to create, remove, and get a playlist, which consists of a list of items (each of which has a title and url).

Note: {playlist_id} should be some sort of int.

Method Endpoint Description
GET /playlist/{playlist_id}/items

Get items from specified playlist.

Response Codes

  1. 200: Operating successful.
  2. 404: Invalid playlist_id.

Response Body (JSON)

{
  "total": int,
  "items": [{"title": str, "url": str}, ...]
}
POST /playlist/{playlist_id}/items

Add items to specified playlist.

Request Payload (JSON)

{
  "items": [{"title": str, "url": str}, ...],
  "position": int
}

Response Codes

  1. 200: Operating successful.
  2. 404: Invalid playlist_id.

Response Body (JSON)

{"total": int}
DELETE /playlist/{playlist_id}/items

Remove items from specified playlist.

Response Codes

  1. 200: Operating successful.
  2. 404: Invalid playlist_id.

Response Body (JSON)

{"total": int}

The last three operations allow you to get the items of a playlist, add items to a playlist, and remove items from a playlist.

Spotify¶

The design of playlist REST API is based on the Spotify Playlists API.
