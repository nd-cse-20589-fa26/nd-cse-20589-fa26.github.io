Activity 1: curlit (0.8 Points)¶

For this activity, write a Python script, curlit.py, that implements a subset of the curl utility:

# Display usage message
$ ./curlit.py
Usage: curlit [-v -H HEADER] URL

# Curl this webpage
$ ./curlit.py https://pnutz.h4x0r.space/courses/cse.20589.fa26/homework08.html
<!doctype html>
<html lang="en">
<head>
...

# Curl this webpage with verbosity
$ ./curlit.py -v https://pnutz.h4x0r.space/courses/cse.20589.fa26/homework08.html
< HTTP/1.1 200 OK
< Server: nginx/1.28.3
< Date: Mon, 02 Nov 2026 04:03:44 GMT
< Content-Type: text/html
< Content-Length: 16746
< Last-Modified: Mon, 02 Nov 2026 04:03:17 GMT
< Connection: close
< ETag: "6ae80b85-416a"
< Accept-Ranges: bytes
...

# Curl with custom header
$ ./curlit.py -H 'User-Agent: Homework08/Fall2026' https://ip.yld.me/User-Agent
Homework08/Fall2026

The curlit.py takes a URL argument and a series of optional flags:

  • -v: This enables verbose information (ie. display the HTTP headers before the HTTP contents).

  • -H HEADER: This allows the user to add additional HTTP headers as part of the request (must be in the format KEY: VALUE.

If no scheme is provided in the URL then http is assumed. Likewise, if no port is provided, then 80 is assumed. Finally if no path is provided, then / is assumed.

Task 1: curlit.py¶

To implement the curlit.py script, you will need complete the following:

Classes¶

The first class you will need to implement is HTTPConnection:

  • @dataclass
class HTTPConnection:
    host:       str
    port:       int
    use_ssl:    bool=False

    This implements the context manager protocol such that the __enter__ method allocates a socket using socket.create_connection to the given host and port and __exit__ performs socket.close.

    Hint: If use_ssl is True, then you can use ssl.create_default_context and SSLContext.wrap_socket as described in socket creation to provide encrypted communication on the socket.

The second class you will need to implement is HTTPResponse:

  • @dataclass
class HTTPResponse:
    status:     str
    headers:    dict[str, str]
    text:       str

    This stores the result of HTTP request (ie. the status message, all the headers, and the HTTP content text) and a provides a few utility methods for accessing the HTTP status_code, the text contents as bytes, and the text contents as JSON.

    Hint: All these methods should be one-liners.

Functions¶

Once you have the classes above, you can then implement the following functions:

  • def get(url, headers: Optional[dict[str, str]]=None) -> HTTPResponse:

    This function parses the url, performs a HTTP request using the given headers, and then returns a HTTPResponse with the results.

    Hints:

    • You can use urlsplit to parse the url to determine the scheme, host, port, and *path.

    • You will need to handle the situations where the url does not specify a component (ie. scheme, port, or path) and fall back to the appropriate default.

    • You will want to ensure you set the Host HTTP header.

    • You should use your HTTPConnection class to make a connection.

    • You should use socket.makefile to get a reader and writer stream.

    • Remember that a HTTP transaction looks like the following:

      GET $PATH HTTP/1.0\r\n    # HTTP Request Method
Host: $HOST\r\n           # HTTP Request Headers
Key: Value\r\n
...
\r\n                      # HTTP Request Sentinel
HTTP/1.0 200 OK\r\n       # HTTP Response Status
Key: Value\r\n            # HTTP Response Headers
...
\r\n                      # HTTP Response Sentinel
Contents                  # HTTP Response Contents

  • def curlit(url: str, headers: Optional[dict[str, str]]=None, verbose: bool=False):

    This function performs a HTTP GET request on specified url with given headers. If verbose is True, then output status and headers before text.

    Hints: Use the get function and access the headers from the HTTPReponse object.

  • def main(arguments: list[str]=sys.argv[1:]) -> None:

    This function parses the command line arguments and then performs the HTTP GET request on the specified url.

    Hints: The str.split function has a maxsplit keyword argument. Use curlit to perform the actual HTTP GET request.
