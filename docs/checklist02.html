Overview¶

Here is a general outline of the key concepts (arranged by topic) that you should know for Exam 02.

The exam will have the following format:

  1. Shell: Identify ways to perform certain tasks using networking commands, filters, or pipelines (multiple-choice, fill-in-the-blank).

  2. Python - Sorting: Debug, fix, test, and evaluate a Python script that involves sorting data in JSON format. (multiple-choice, fill-in-the-blank).

  3. Python - Functional Programming: Debug, fix, test, and evaluate a Python script that involves the functional programming, iterators, generators, and the iterator protocol. (multiple-choice, fill-in-the-blank).

  4. Python - Object-Oriented Programming: Debug, fix, test, and evaluate a Python script that involves object-oriented programming, processes, and the context manager protocol. (multiple-choice, fill-in-the-blank).

  5. Python - Translations: Convert pipelines to Python code (coding on the computer).

Parts 1 through 4 are to be done first on paper. Once that portion is completed and submitted, you will do part 5 on your own computer and submit code to your assignments repository.

Note: Using signals will not be on Exam 02.

Representative, But Not Exhaustive¶

This checklist is meant to be representative, rather than exhaustive (ie. there may be questions that show up on the exam that are not shown below).

Logistics¶

Exam 02 will take place during our normal lecture session on Wednesday, October 14 from 11:30 AM - 12:20 PM in 303 Cushing Hall.

As noted above, the first portion of the exam with be on paper, while the remaining component with require coding and submitting work to your assignments GitHub repository.

For the coding portion, students will use their own computer, and thus are permitted access to any material in their textbooks, notes, assignments, and the Internet.

Honor Code Violations¶

Although students are allowed to use their computers and the Internet during the coding portion of the exam, students may not communicate with others or solicit answers from others. Nor may they use AI tools such as ChatGPT or Co-Pilot during the exam. Students caught sharing solutions or violating any portion of the honor code will receive a zero on the exam.

Furthermore, students are not allowed to consult, copy, or share material from previous sections of this course.

Shell¶

Networking¶

Concepts¶

  • What is an IP address? How is a domain name related to it?

    You should know the commands to lookup this information.

  • What is a network port?

    You should know how to scan for ports and how to connect to a machine at a specific a domain or address and port number.

  • What is bandwidth and latency?

    You should know what each measures and what programs we would use to perform these measurements.

Commands¶

Command Description
ip List the IP addresses of the current machine.
host Lookup IP addresses corresponding to domain.
nmap Scan remote machine for open ports.
nc General purpose tool to communicate with network services.
curl Perform a HTTP request.
ping Measure delay from host to remote machine.

Functions¶

Function Description
map(func, seq) Apply function to each element in sequence.
filter(func, seq) Apply function to each element in sequence and keep ones that return True.
iter(iterable) Gets iterator from iterable object.
next(iterator) Gets next element from iterator.
