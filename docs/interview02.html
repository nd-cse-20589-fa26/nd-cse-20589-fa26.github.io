Sample Interview¶

Here is an example of the types of tasks the interviewer mask ask you to perform:

  • Create a new practice02 folder in the assignments repository and go into it.

  • Write a pipeline to list all the unique users with a process on the current system in (ascending order by name).

    Note: use LC_ALL=C sort when ordering.

  • Write a Python script called practice02.py that performs the same task.

    • Use os.popen for the first command in the pipeline.

    • Use at least two of the following: functional programming, list comprehensions, or generator expressions.

    • Make sure output has no duplicates and is ordered.

Hints¶

  • You should be familiar with using data structures in Python such as lists and dicts.

  • You should be familiar with using os.popen to read output from another program.

  • You should be familiar with using map, filter, and lambda to perform functional programming.

  • You should be familiar with using list comprehensions.

  • You should be familiar with using generator expressions.

  • You should be familiar with using with to manage resources properly.

  • You should be familiar with identifying data parallelism and task parallelism.

Consulting Resources¶

As with your Reading and Homework assignments, you are allowed to consult the course texts, slides, notes, the Internet, and even AI tools. However, you cannot communicate with anyone else nor can you ask an AI tool to generate a solution.

Be mindful that the interviewer is assessing your proficiency and how much you have internalized. Over reliance on any external resource will be viewed negatively in regards to your mastery of the material.
