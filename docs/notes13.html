Filters: Sed¶

sed allows us to modify streams of text using regular expressions.

# Shell: replace all numbers in IP address with
# a single x

$ cat /etc/hosts | sed -E 's/[0-9]{1,3}/x/g'
...
x.x.x.x weasel
x.x.x.x banshee
x.x.x.x xavier
x.x.x.x momo

# Python: replace all numbers in IP address with
# a single x

path = '/etc/hosts'
rx   = r'[0-9]{1,3}'

with open(path) as stream:
    for line in stream:
        print(re.sub(rx, 'x', line), end='')

Example: cse-curriculum.py¶

Given the Computer Science Curriculum (yld.me/mbfL):

  1. How many MATH vs PHYS vs CSE courses?

  2. How many sophomore CSE courses?

#!/usr/bin/env python3

import os
import re
import requests

URL = 'https://yld.me/mbfL'

# 1. How many MATH vs PHYS vs CSE courses?

os.system(f"""
curl -sL {URL} \
        | grep -Eo '(MATH|PHYS|CSE) [0-9]{5}' \
        | awk '{print $1}' \
        | sort | uniq -c
""")

response = requests.get(URL)
counts   = {}

for line in response.text.splitlines():
    for department in re.findall(r'(MATH|PHYS|CSE) [0-9]{5}', line):
        counts[department] = counts.get(department, 0) + 1

for department, count in sorted(counts.items()):
    print(f'{count:>7} {department}')

# 2. How many sophomore CSE courses?

os.system(f"""
curl -sL {URL} \
        | grep -Eo 'CSE 2[0-9]{4}' \
        | awk '{print $1}' \
        | wc -l
""")

response = requests.get(URL)
courses  = re.findall(r'CSE 2[0-9]{4}', response.text, flags=re.MULTILINE)
print(len(courses))

Sorting: Overview¶

To order a sequence of values in Python, we can use the sorted function on the sequence to get a new list:

  • Uses TimSort (which is a hybrid algorithm: merge sort, insertion sort)

  • O(nlogn) time complexity

  • Stable ordering

# Make a list of numbers
>>> numbers = [5, 4, 7, 0, 1]

# Make a new list with values in ascending order
>>> sorted(numbers)
[0, 1, 4, 5, 7]

# Original list is unmodified
>>> number
[5, 4, 7, 0, 1]

Sorting: In-Place¶

# Make a list of numbers
>>> numbers = [5, 4, 7, 0, 1]

# Sort values in ascending order in-place
>>> numbers.sort()

# Original list is modified
>>> numbers
[0, 1, 4, 5, 7]

Sorting: Reverse¶

# Make a list of numbers
>>> numbers = [5, 4, 7, 0, 1]

# Make a new list with values in descending order
>>> sorted(numbers, reverse=True)
[7, 5, 4, 1, 0]

Sorting: Key, Lambda¶

# Make a list of words
>>> words = 'notre dame go irish'.split()

# Sort words alphabetically
>>> sorted(words)
['dame', 'go', 'irish', 'notre']

# Sort words by length
>>> sorted(words, key=len)
['go', 'dame', 'notre', 'irish']

# Make a list of words
>>> words = 'notre dame go irish'.split()

# Function that returns last letter
>>> def last(w): return w[-1]

# Sort words by last letter using function
>>> sorted(words, key=last)
['notre', 'dame', 'irish', 'go']

# Sort words by last letter using lambda
>>> sorted(words, key=lambda w: w[-1])
['notre', 'dame', 'irish', 'go']

Sorting: Multi-Factor¶

Since Python uses TimSort, which is a stable sorting algorithm, to order values by multiple factors, we can either do:

Multiple Sorts (lowest priority to highest priority)

# Make a list of words
>>> words = 'notre dame go irish'.split()

# Sort alphabetically and then by length
>>> sorted(sorted(words), key=len)
['go', 'dame', 'irish', 'notre']

Complex Comparison (highest priority to lowest priority)

# Make a list of words
>>> words = 'notre dame go irish'.split()

# Compare by length, then alphabetically
>>> sorted(words, key=lambda w: (len(w), w))

Sorting: Min, Max¶

# Make a list of words
>>> words = 'notre dame go irish'.split()

# Get smallest and largest words (alphabetically)
>>> min(words), max(words)
('dame', 'notre')

# Get smallest and largest words (by length)
>>> min(words, key=len), max(words, key=len)
('go', 'notre')
