Notes 01: Unix Programming Environment

  • Home

A. Login, Home Directory¶

Login to a student machine¶

0. ssh (using Windows terminal)

Determine my location (what is my $HOME)¶

1. pwd

After we login, we are running a program called a shell (which is an interpreter). It translates commands on the fly (vs. a compiler** such as gcc that translates ahead of time).

View environment variables¶

2. env
   env | less

Print value of a variable¶

3. echo $SHELL

Change value of a variable¶

4. SHELL=/usr/bin/python3

B. Files, Flags, Help¶

Create empty file¶

5. touch lyrics.txt

List contents of directory¶

6. ls

List contents of directory (metadata)¶

7. ls -l

Read documentation¶

8. man ls
   tldr ls

Show usage message¶

9. ls --help
   ls --help | less

C. Aliases, Configuration¶

View all aliases¶

10. alias

Create an alias¶

11. alias ls='ls -la'

Test an alias¶

12. la

Open another terminal and observe that new instance of shell does not have alias of previous shell. Need to edit ~/.bashrc to make it persist.

Edit bash configuration¶

13. vim ~/.bashrc

View contents of file¶

14. cat ~/.bashrc

Load settings into current shell¶

15. source ~/.bashrc

D. Navigation, Directories, Management¶

Create directory¶

16. mkdir songs

Move file¶

17. mv lyrics.txt songs

Go into directory¶

18. cd songs

Go back to previous directory¶

19. cd -    cd -

Rename file¶

20. mv lyrics.txt song.txt

Edit file¶

21. vim song.txt

Copy file¶

22. cp song.txt copy.txt

View differences between files¶

23. diff song.txt copy.txt

Go back to parent directory¶

24. cd ..

Remove directory and its contents¶

25. rm -fr songs
