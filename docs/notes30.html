SQLite: Overview¶

A relational database is a collection of data organized into tables that consist of rows of items that correspond to columns:

  • Has measures for data integrity.

  • Allows for combining multiple datasets.

  • Enables asking detailed questions.

  • Provides scalable performance.

SQLite is a lightweight and embeddable relational database implementation.

SQLite: Structure¶

  • Every database consists of tables that have a relationship.

  • Each table consists of rows and columns.

  • Each column has a name and a type.

    • Duplicates?
    • Empty?
    • Default?

  • Each row is the actual data.

SQLite: Interfaces¶

We can interact with a SQLite database via the command line interface:

# Interact with doornote.db sqlite database
$ sqlite3 doornote.db
SQLite version 3.46.1 2024-08-13 09:16:08
Enter ".help" for usage hints.
sqlite> .tables
Messages

We can interact with a SQLite database via a graphical interface such as SQLite Browser.

SQL: Overview¶

To programmatically interact with a SQLite database, we use SQL (Structured Query Language):

Verb Description
CREATE Create a table and specify its columns.
DROP Remove a table.
INSERT Add row(s) to a table.
UPDATE Update row(s) in a table.
DELETE Remove row(s) from a table.
SELECT Get row(s) from a table.

Python + SQLite: Cursors / Transactions¶

To perform SQL operations, we first create a cursor and then use it to execute SQL statements:

class Database:
  ''' Database: Stored in SQLite'''

  SQL_CREATE_MESSAGES = '''
  CREATE TABLE IF NOT EXISTS Messages(
      id          INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT,
      room        VARCHAR(20) NOT NULL,
      message     VARCHAR(500) NOT NULL
  )
  '''
  ...

  def __init__(self, path='doornote.db'):
      ...

      # Use database transaction (automatic commit)
      with self.conn:
          # Get cursor to database
          cursor = self.conn.cursor()

          # Execute SQL statement
          cursor.execute(self.SQL_CREATE_MESSAGES)

Using the with statement causes the database operations to occur as a single transaction (ie. everything happens or nothing happens).

Python + SQLite: Statements¶

Rather than manually interpolating SQL statements, we can use the execute method to prepare SQL values for us:

class Database:
    ''' Database: Stored in SQLite'''
    ...
    SQL_INSERT_ROOM_MESSAGE  = 'INSERT INTO Messages(room, message) VALUES (?, ?)'
    SQL_SELECT_ROOM_MESSAGES = 'SELECT message FROM Messages WHERE room=?'
    SQL_SELECT_ROOM_COUNT    = 'SELECT Count(*) FROM Messages WHERE room=?'
    ...
    def messages(self, room: str) -> list[str]:
        ''' Return messages associated with room. '''
        with self.conn:
            cursor = self.conn.cursor()
            cursor.execute(self.SQL_SELECT_ROOM_MESSAGES, (room,))
            return [row[0] for row in cursor.fetchall()]

    def append(self, room: str, message: str):
        ''' Add message to end of list associated with room. '''
        with self.conn:
            cursor = self.conn.cursor()
            cursor.execute(self.SQL_INSERT_ROOM_MESSAGE, (room, message))

    def count(self, room: str) -> int:
        ''' Return number of messages for room. '''
        with self.conn:
            cursor = self.conn.cursor()
            cursor.execute(self.SQL_SELECT_ROOM_COUNT, (room,))
            return cursor.fetchone()[0]

Using prepared SQL statements is one way to avoid SQL injections!
