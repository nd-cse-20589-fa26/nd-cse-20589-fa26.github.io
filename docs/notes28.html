Review: REST¶

REST (representational state transfer) and is a software architecture style that defines a pattern for client and server interactions.

  1. Stateless: The server won't maintain any state between requests from the client.

  2. Client-server: The client and server must be decoupled from each other, allowing each to develop independently.

  3. Uniform interface: The server will provide a uniform interface for accessing resources without defining their representation.

Review: Endpoints¶

To define a REST API, it is necessary to describe the HTTP methods and endpoints (ie. URL paths), along with any parameters they may take.

POST/PUT /greeting Set greeting to greeting greeting: str

Vial: hello_app.py¶

Implement hello_app.py using [Vial].

$ curl --json '{"greeting": "Hola"}' localhost:9999/greeting    # Set greeting to Hola
{"greeting": "Hola", "default_name": "Unknown"}

$ curl localhost:9999/greeting?name=Huzz                        # Get greeting for Huzz

#!/usr/bin/env python3

import sys

from vial import Vial

# Constants

try:
    HOST = sys.argv[1]
    PORT = int(sys.argv[2])
except IndexError:
    print(f'Usage: {sys.argv[0]} HOST PORT', file=sys.stderr)
    sys.exit(1)

# Globals

App = Vial(HOST, PORT, {'greeting': 'Hello', 'default_name': 'Unknown'})

# Handlers

@App.route('/greeting')
def greet(request):
    name = request.query_data.get('name', App.default_name)
    return f'{App.greeting}, {name}!'

@App.route('/greeting', methods=['POST', 'PUT'])
def update(request):
    App.greeting     = request.form_data.get('greeting', App.greeting)
    App.default_name = request.form_data.get('name', App.default_name)
    return {'greeting': App.greeting, 'default_name': App.default_name}

# Main Execution

if __name__ == '__main__':
    App.run()

Testing: Overview¶

When building software systems, it is often necessary to determine whether or not the program is correct. In the absence of proofs, developers utilize testing:

Functional Performance Unit
Check that program performs the correct functionality. Check that program performs within the desired time and resource constraints. Check that individual components of program work correctly.

Unit Tests: unittest¶

Inspired by JUnit, Python provides unittest as a unit testing framework that provides test automation.

  1. Test Fixtures:

    Preparation needed to perform tests, along with any cleanup.

  2. Test Cases:

    Collection of methods that check response to particular set of inputs.

  3. Test Suites

    Collection of test cases.

  4. Test Runner

    Orchestrates test execution and outputs the results.

import unittest

class TestStringMethods(unittest.TestCase):
    def test_upper(self):
        self.assertEqual('foo'.upper(), 'FOO')

    def test_isupper(self):
        self.assertTrue('FOO'.isupper())
        self.assertFalse('Foo'.isupper())

if __name__ == '__main__:
    unittest.main()

Unit Test: Test Cases¶

A test case is created by subclassing unittest.TestCase and defining individual test methods:

import os
import requests
import unittest

class HelloTest(unittest.TestCase):               # Test Case
    host = '127.0.0.1'
    port = 9999

    def test_01_greeting_get_default(self):       # Individual Test Method
        # Perform operation and get results
        endpoint = f'http://{self.host}:{self.port}/greeting'
        response = requests.get(endpoint)

        # Assertions that compare output with expected result
        self.assertEqual(response.status_code, 200)
        self.assertEqual(response.text, 'Hello, Unknown!')

    def test_02_greeting_get_name(self):          # Individual Test Method
        # Perform operation and get results
        endpoint = f'http://{self.host}:{self.port}/greeting'
        params   = {'name': os.environ['USER']}
        response = requests.get(endpoint, params=params)

        # Assertions that compare output with expected result
        self.assertEqual(response.status_code, 200)
        self.assertEqual(response.text, f'Hello, {os.environ["USER"]}!')

if '__name__' == '__main__':
    unittest.main()

The individual test methods are executed in lexicographical order.

Unit Test: Test Fixtures¶

The setUpClass and tearDownClass methods are used to define instructions that will be executed before and after all test methods.

def find_open_port(start: int=9000, end: int=9999) -> int:
    # Get used ports
    with os.popen("ss -tlpn | awk '{print $4}' | cut -d : -f 2") as stream:
        used_ports = {int(port) for port in stream if port.strip().isnumeric()}
        # Generate random port in range until we find one not in use
        while (port := random.randint(start, end)) in used_ports: pass
        return port

class HelloTest(unittest.TestCase):

    @classmethod
    def setUpClass(cls):
        cls.host    = '127.0.0.1'                   # Use localhost
        cls.port    = str(find_open_port())         # Find open port
        cls.logfile = open('hello_app.log', 'w')    # Open log file
        cls.process = subprocess.Popen(             # Start web application
            ['python3', '../slides27/hello_app.py', cls.host, cls.port],
            stdout  = cls.logfile,                  # I/O redirection
            stderr  = cls.logfile
        )
        time.sleep(0.25)                            # Let web application start

    @classmethod
    def tearDownClass(cls):
        cls.process.terminate()                     # Kill web application
        cls.process.wait()                          # Clean up child process
        cls.logfile.close()                         # Close log file

#!/usr/bin/env python3

import json
import os
import random
import requests
import subprocess
import time
import unittest

# Functions

def find_open_port(start: int=9000, end: int=9999) -> int:
    with os.popen("ss -tlpn | awk '{print $4}' | cut -d : -f 2") as stream:
        used_ports = {int(port) for port in stream if port.strip().isnumeric()}
        while (port := random.randint(start, end)) in used_ports: pass
        return port

# Unit Tests

class HelloTest(unittest.TestCase):
    ''' Hello Unit Tests '''

    @classmethod
    def setUpClass(cls):
        cls.host    = '127.0.0.1'
        cls.port    = str(find_open_port())
        cls.logfile = open('hello_app.log', 'w')
        cls.process = subprocess.Popen(
            ['python3', '../slides27/hello_app.py', cls.host, cls.port],
            stdout  = cls.logfile,
            stderr  = cls.logfile,
        )

        time.sleep(0.25)

    @classmethod

        cls.process.terminate()
        cls.process.wait()
        cls.logfile.close()

    def test_01_greeting_get_default(self):
        # Perform operation and get results
        endpoint = f'http://{self.host}:{self.port}/greeting'

        # Assertions that compare output with expected result
        self.assertEqual(response.status_code, 200)
        self.assertEqual(response.text, 'Hello, Unknown!')

        endpoint = f'http://{self.host}:{self.port}/greeting'
        params   = {'name': os.environ['USER']}
        response = requests.get(endpoint, params=params)

        # Assertions that compare output with expected result
        self.assertEqual(response.status_code, 200)
        self.assertEqual(response.text, f'Hello, {os.environ["USER"]}!')

    def test_03_greeting_bad_method(self):
