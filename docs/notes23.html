Review: Inheritance, Factory Method Pattern¶

  1. What is inheritance?

    Inheritance is a core OOP principle that enables the creation of hierarchical relationships between units to allow for code reuse.

    # Subclass inherits from Path

class PathEntry(Path):
  @property
  def path(self):
      return self.parent / self

# Parent - Abstract Base Class / Interface

@dataclass
class BaseWalker(ABC):
    entry:  os.DirEntry | PathEntry

    @abstractmethod
    def walk(self, recursive: bool=False):
        pass

# Child - Concrete Class inherits from BaseWalker

class NoopWalker(BaseWalker):
    def walk(self, recursive: bool=False):
        pass

  2. What is the factory design pattern?

    The factory design pattern uses a specialized factory method that produces instantiated objects. This is done to abstract away complex object instantiation logic.

    # Child - Concrete Class inherits from BaseWalker

class FileWalker(BaseWalker):
    def walk(self, recursive: bool=False):
        print(f'{self.entry.path} {self.entry.stat().st_size}')

# Child - Concrete Class inherits from BaseWalker

class DirectoryWalker(BaseWalker):
    def walk(self, recursive: bool=False):
        try:
            with os.scandir(self.entry.path) as entries:
                for entry in map(WalkerFactory.get_walker, entries, cycle([recursive])):
                    entry.walk(recursive)
        except PermissionError:
            pass

# Concrete Creator

class WalkerFactory:
    @classmethod
    def get_walker(cls, entry: os.DirEntry | PathEntry, recursive: bool=False) -> BaseWalker:
        match stat.S_IFMT(entry.stat().st_mode):
            case stat.S_IFREG: return FileWalker(entry)
            case stat.S_IFDIR: return DirectoryWalker(entry) if recursive else NoopWalker(entry)
            case _:            return NoopWalker(entry)

Advantages:

  • Separation of Concerns: Separate the what (business logic) from the how (concrete implementation details)

  • Open/closed Principle: extend units (functions, classes) without modification.

  • Should make it easier to add new types (ie. symlinks)

I/O: Overview¶

All input and output is performed on files:

  1. Open

    Acquire handle to stream of data.

  2. Close

    Release handle to stream of data.

  1. Read

    Load chunk from stream of data.

  2. Write

    Store chunk to stream of data.

  3. Seek

    Move within stream of data.

  • Q: What is a file?

  • A: A sequence or stream of bytes (stored in blocks)

  • Skit: Perform system calls on file, show man pages, blocking

Implementation¶

def copy_file(src: Path, dst: Path):
    try:
        rfd = os.open(src, os.O_RDONLY)
        wfd = os.open(dst, os.O_WRONLY | os.O_CREAT, src.stat().st_mode)
    except OSError as e:
        print(e, file=sys.stderr)
        sys.exit(1)

    while data := os.read(rfd, BUFSIZ):
        os.write(wfd, data)

    os.close(rfd)
    os.close(wfd)

I/O: file_array.py¶

Create a persistent array that supports the index operator.

# Create Persistent Array
array = FileArray('array.txt')

# Write to Persistent Array
for index, char in enumerate('hello, world'):
    array[index] = char.encode()

# Write to Persistent Array (again)
for index, char in enumerate('goodbye, all'):
    array[(1<<8) + index] = char.encode()

Implementation¶

@dataclass
class FileArray:
    path:   str                 # Path to file/array
    size:   int=(1<<10)         # Size of file/array

    def __post_init__(self):
        ''' Post constructor: open file and allocate space. '''
        self.fd = os.open(self.path, os.O_RDWR | os.O_CREAT, 0o644)
        os.posix_fallocate(self.fd, 0, self.size)

    def __del__(self):
        ''' Destructor: close file '''
        os.close(self.fd)

    def __getitem__(self, key: int) -> bytes:
        ''' Get item at key '''
        if key >= self.size:
            raise IndexError

        os.lseek(self.fd, key, os.SEEK_SET)
        return os.read(self.fd, 1)

    def __setitem__(self, key: int, value: bytes):
        ''' Set item at key with value '''
        if key >= self.size:
            raise IndexError

        os.lseek(self.fd, key, os.SEEK_SET)
        os.write(self.fd, value)
