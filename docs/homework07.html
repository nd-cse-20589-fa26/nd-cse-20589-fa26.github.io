Activity 2: findit (0.8 Points)¶

For this activity, write a Python script, findit.py, that implements a subset of the find utility:

# Display usage message
$ ./findit.py
Usage: findit ROOT [FILTERS]

Filters:
    -type [f|d]     File is of type f for regular file or d for directory
    -name PATTERN   Name of file matches shell pattern
    -empty          File or directory is empty
    -readable       File is readable by user
    -writable       File is writable by user
    -executable     File is executable or directory is searchable by user

# Display entries in current directory
$ ./findit.py .
.
__pycache__
findit.test
findit.py
findit.py.template
Makefile
answers.json
__pycache__/findit.cpython-314.pyc

# Display only files that end with .py
$ ./findit.py . -type f -name *.py
findit.py

The findit.py takes a ROOT argument and then a series of optional FILTERS:

  • -type [f|d]: This allows the user to specify whether or not to search for files or directories (note, cannot be a symlink).

  • -name PATTERN: This allows the user to specify a shell pattern to match against the name of the file.

  • -empty: This allows the user to specify searching for empty files or directories.

  • -readable: This allows the user to specify search for entries that are readable by the user.

  • -writable: This allows the user to specify search for entries that are writable by the user.

  • -executable: This allows the user to specify search for entries that are executable by the user.

If multiple FILTERS are specified, then they all must match in order for the file or directory to be displayed.

Task 1: findit.py¶

To implement the findit.py script, you will need to use the inheritance and the factory method pattern discussed in class.

Filters¶

Each of the command line FILTERS in findit.py corresponds to a specific BaseFilter class:

class BaseFilter(ABC):
    ''' Filter Interface'''
    @abstractmethod
    def check(self, path: Path) -> bool:
        pass

As can be seen, the provided BaseFilter is an abstract base class which requires subclasses to implement the check abstract method. The purpose of this method is to return True if the given path passes the FILTER.

You will need to implement each of the following methods in the corresponding concrete classes:

  • class FilterFilter:
    def check(self, path: Path) -> bool:

    This returns True if the given path is a regular file and not a symlink.

    Hint: Use the methods of the Path object or a function in os.path.

  • class DirectoryFilter:
    def check(self, path: Path) -> bool:

    This returns True if the given path is a directory and not a symlink.

    Hint: Use the methods of the Path object or a function in os.path.

  • @dataclass
class NameFilter:
    pattern: str
    def check(self, path: Path) -> bool:

    This returns True if the name of given path matches stored shell pattern.

    Hint: Use fnmatch.fnmatch.

  • class EmptyFilter:
    def check(self, path: Path) -> bool:

    This returns True if the given path is empty (must be a file or directory, no symlink).

    Hint: Use the methods of the Path object or a function in os.path.

    Think carefully on what it means for a file or directory to be empty.

  • class ReadableFilter:
    def check(self, path: Path) -> bool:

    This returns True if the given path is readable.

    Hint: Use os.access.

  • class WritableFilter:
    def check(self, path: Path) -> bool:

    This returns True if the given path is writable.

    Hint: Use os.access.

  • class ExecutableFilter:
    def check(self, path: Path) -> bool:

    This returns True if the given path is executable.

    Hint: Use os.access.

Factory¶

Once you have implemented the Filter classes, you are to complete the factory method pattern:

  • class FilterFactory:
    @classmethod
    def get_filter(cls, arguments: list[str]) -> BaseFilter:

    This returns the next concrete Filter class based on the given command line arguments (raise UnknownFilter if invalid argument).

    Hint: You should consume at least one argument (and sometimes two depending on the Filter).

Walk¶

You will use these Filters and the factory method in the following walk function:

  • def walk(root: Path, filters: list[BaseFilter]) -> None:

    This function prints root if it passes all filters and then recursively walks root and prints any entries that pass all filters.

    Hint: Use Path.walk to perform the walk. Consider using all with a generator expression to check all the filters. You can also use itertools.chain to combine two separate iterables into a single sequence.

Main Execution¶

Finally, you will need to parse command line arguments and perform the walk:
