Overview¶

Here is a general outline of the key concepts and commands (arranged by topic) that you should know for Exam 01.

The exam will have the following format:

  1. Git, Shell: Identify ways to perform certain tasks using git and in the shell (multiple-choice, fill-in-the-blank).

  2. Files, Processes, I/O Redirection: Identify ways to perform operations on files and processes, and to redirect I/O (multiple-choice, fill-in-the-blank).

  3. Python Scripting: Debug, fix, test, and evaluate a Python script (multiple-choice, fill-in-the-blank).

  4. Data Structures: Manipulate and utilize data structures such as lists and dicts in Python (multiple-choice, fill-in-the-blank).

  5. Regular Expressions: Use regular expressions in Python to answer some questions (coding on the computer).

Parts 1 through 4 are to be done first on paper. Once that portion is completed and submitted, you will do part 5 on your own computer and submit code to your assignments repository.

Note: Using requests, csv, and json will not be on Exam 01.

Representative, But Not Exhaustive¶

This checklist is meant to be representative, rather than exhaustive (ie. there may be questions that show up on the exam that are not shown below).

Nor may they use AI tools such as ChatGPT or Co-Pilot during the exam. Students caught sharing solutions or violating any portion of the honor code will receive a zero on the exam.

Furthermore, students are not allowed to consult, copy, or share material from previous sections of this course.

Files, Processes, I/O Redirection¶

Concepts¶

Files¶

  • What is the general layout or hierarchy of a typical Unix filesystem?

    You should be familiar with the most common directories found in a typical Unix filesystem (e.g. /bin, /etc, /lib, /usr, /tmp, /var, etc.).

  • What is the difference between an absolute and relative path?

    You should know how to reference a file using both methods.

  • How do Unix file permissions work? How would you set them to restrict access for certain operations and certain classes?

    You should be able to translate from octal to rwx triplets and back.

Processes¶

  • What is a process? What attributes does it have?

    You should know at a high-level the typical attributes of a process (ie. PID, UID, etc.).

  • What does it mean to signal a process? What do different the different signals do (TERM, INT, KILL)?

    You should know the difference between terminating a process gracefully and terminating it forcefully.

  • How do we suspend, foreground, and background a process?

    You should know the appropriate keybindings and commands to perform these actions.

I/O Redirection¶

  • What three files does every process start with?

  • How do you redirect the output of a command into a new file?

  • How do you redirect the output of a command and append it to a file?

  • How do you redirect the output of one command as the input to another?

  • How do you direct the contents of a file into the input of command?

  • What is /dev/null? How would you use it to output stderr but ignore stdout of a program?

Commands¶

  1. ls

    List the contents of a directory (long, human-readable, sorted)

  2. chmod

    Set permissions using octal and symbolic arguments.

  3. stat

    View the inode information for a file.

  4. find

    Search directory for files by name and type.

  5. ps

    List the processes for the current user and for the whole system.

  6. kill

    Signal a process by PID.

  7. pkill

    Signal a process by name.

Sample Questions¶

  1. Which of the following commands makes a file executable?

    • chmod +x file
    • stat file
    • make file
    • test -x file

  2. Which of the following commands shows the meta-data of a file?

    • ls -l file
    • stat file
    • du file
    • find file

  3. Which of the following commands forcefully terminates a process?

    • kill PID
    • kill -9 PID
    • sudo kill PID
    • kill -KILL PID

  4. Suppose we were running cat. How would we signal to the program that we are done inputting text?

    • Control-Z
    • Control-I
    • Control-D
    • Control-C

  5. Which of the following pipelines counts all the "Permission denied" errors encountered when recursively searching file names under the "/etc" directory?

    • find /etc > /dev/null | wc -l
    • find /etc 2>&1 > /dev/null | wc -l
    • find /etc 2> /dev/null | wc -l

    • find /etc > /dev/null 2>&1 | wc -l

  6. Which of the following appends the standard output of a program to a file?

    • program > output
    • program 2> output
    • program >> output

    • program &> output
